## ProjectRC · 로컬 랜덤 대화 앱

### 현재 동작
- 서버 주소: `http://192.168.0.2:3000`
- 공기계와 PC가 같은 Wi-Fi에 연결되면 Android 앱에서 서버에 접속할 수 있다.
- Android 앱: 라운지(게시물·24시간 스토리), 랜덤 1:1 매칭, 메시지, 사진·영상 업로드, 프로필 사진 등록.
- 관리자: PC 브라우저에서 `http://192.168.0.2:3000/review`로 접속해 신고·미디어 승인과 저장된 대화방을 페이지별로 조회한다. 열람은 감사 기록에 남는다.

### 폴더 구조
```text
ProjectRC/
├─ android/       Android 소스와 build.ps1, build/의 APK
├─ public/        웹 라운지와 관리자 화면
├─ data/          SQLite 데이터베이스와 백업
├─ private/       로컬 담당자 토큰 파일 (Git 제외)
├─ test/          서버 자동 테스트
├─ README.md      설치·실행·공기계 테스트 순서
└─ API_GUIDE.txt  API와 관리자 사용법
```

### 공기계 실행 순서
1. PC에서 `start-phone.cmd`를 실행한다.
2. 공기계와 PC를 같은 Wi-Fi에 연결한다.
3. 공기계 브라우저에서 `http://192.168.0.2:3000/app.apk`를 열어 APK를 내려받아 설치한다.
4. 앱을 열고 **내 설정**에서 서버 연결을 확인한다. 기본 주소는 이미 `http://192.168.0.2:3000`이다.
5. 테스트 계정을 만든 뒤 라운지 또는 대화 탭에서 기능을 확인한다.

### 토큰
- 담당자 토큰은 `private/LOCAL_TOKENS.txt`에만 둔다.
- 발급: `node admin.js create-reviewer-to-file "테스트 담당자"`
- 토큰 원문은 노션, Git, 공유 문서에 기록하지 않는다.
