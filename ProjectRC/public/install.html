공기계에
모먼트 설치하기

이 페이지는 같은 집 공유기에 연결된 공기계용 개발 테스트 안내입니다.

APK 다운로드 ↗
  1. 위 APK 다운로드를 누릅니다.
  2. 다운로드가 끝나면 알림이나 파일 앱에서 moment-local-debug.apk를 누릅니다.
  3. 설치 허용을 묻는 경우, 이 브라우저 또는 파일 앱의 이 출처의 앱 설치 허용을 켭니다.
  4. 설치 후 모먼트 로컬을 열고 아래 서버 주소를 입력합니다.
  5. 서버 연결 확인 → 테스트 계정 만들기 순서로 누릅니다.

서버 연결 확인이 실패하면 PC와 공기계가 같은 공유기에 있는지 확인하세요. 집 공유기일 때만 PC Windows 네트워크를 개인으로 바꾸고 방화벽 안내를 따르세요.
