# RandomChat 프로젝션 소개

모먼트(Moment) 랜덤채팅 앱은 같은 공유기에 연결된 PC 에서 Node.js 와 SQLite 기반 서버 + Android 공기계 클라이언트( moment-local-debug.apk )를 통해 실시간 랜덤 1:1 매칭, 사진/영상 콘텐츠 업로드 및 게시물을 제공하는 모바일 채팅 플랫폼입니다.

**목표**: 사용자를 서로 매칭시키고, 사용자별로 생성한 콘텐츠를 공유하여 다양한 사회적 관계와 소통을 가능하게 합니다.

---

# 🧩 기술 스택

- **서버**: PC (Node.js + SQLite)
- **포트**: 3000
- **클라이언트**: Android 기기용 .apk 파일
- **통신 방식**: LAN HTTP 기반

---

# 📱 주요 기능 및 시스템

## 1️⃣ 실시간 매칭 시스템

- 사용자를 랜덤으로 1:1 매칭
- 매칭 성공 시 이미지 업로드 가능 (비대기)
- PC 에서 서버 실행, 스마트폰에서 클라이언트 활용

## 2️⃣ 콘텐츠 관리

### 사진/영상 업로드

- 사용자 간 공유 게시물 생성
- 관리자(사용자 A) 승인 후 게시 및 삭제 가능성
- 중복 업로드 방지: 동일 게시물에 이미 존재하는 파일은 재전송하지 않음

### 피드 시스템

- 각 매니지에서 업로드된 콘텐츠 정리 및 표시
- 캐싱으로 불필요한 다운로드 최소화

## 3️⃣ LA N 통신 최적화

- 같은 공유기 환경에서의 HTTP 메시지 전송
- LAN 기반 효율적 데이터 공유
