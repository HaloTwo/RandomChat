현재 구현(2026-09-21): 바탕화면 RandomChat에 웹·Android 라운지와 1:1 채팅 구현. 사용자 공기계 실제 테스트는 아직 하지 않음. 자동 테스트 21개 및 APK 빌드·서명 검증 완료.

수정: Android 라운지 사진/내 글 boolean 형식 통일, LAN HTTP 메시지 UUID 생성, 사진 업로드 실패 시 실행 중인 앱/탭에서 같은 글에 재시도, 변경 없는 피드 이미지 재다운로드 억제, Android 현재 대화방 새로고침.

추가: /review의 관리자 대화 조회. 담당자 토큰으로 전체 방과 저장된 텍스트 메시지를 페이지별 열람. 일반 사용자 접근 차단, 본문 열람 기록 저장. README 및 API_GUIDE.txt에 사용법 기록. 토큰은 data/LOCAL_TOKENS.txt에 보관.

남은 한계: Android는 기능 확인용 화면. 글 생성 요청 자체의 응답 유실/앱 재시작까지 포함한 중복 방지는 추가 보완 필요. 삭제된 대화는 관리자 화면에서도 복구되지 않음.

노션 반영 상태: 브라우저 제어 도구가 failed to write kernel assets (os error 3)로 초기화되지 않아 실제 노션 페이지 저장은 미완료. 이 파일은 옮길 내용이며 노션 반영 완료를 의미하지 않음.

다음: 게시물·스토리의 신고·차단·심사 정책을 추가한다. 집 공유기인지 확인한 뒤 Windows 네트워크를 개인으로 바꾸고 enable-home-phone-access.ps1을 관리자 PowerShell에서 실행한다. 공기계에서 APK 설치 → 서버 연결 확인 → 라운지 글/사진/스토리 → PC 브라우저 매칭 → 사진·영상 승인·재생·캡처 억제를 실제 기기에서 확인한다. 이어서 보관 정책·실제 인증·MFA·결제를 구현한다.
